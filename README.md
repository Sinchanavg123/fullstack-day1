# Simple Blog Website

A simple full-stack blog website built using **HTML, CSS, JavaScript, Node.js, and Express.js**. This project demonstrates the basics of creating and serving a blog application with a clean and responsive user interface.

## Features

* Responsive blog interface
* Create and view blog posts
* Built with Node.js and Express.js
* Simple and easy-to-understand project structure

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js

## Getting Started

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the server:

   ```bash
   npm start
   ```

4. Open your browser and visit:

   ```
   http://localhost:3000
   ```
